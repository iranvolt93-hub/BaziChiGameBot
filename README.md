# بازی‌چی — BaziChiGameBot

ربات مستقل بازی گروهی و انفرادی تلگرام با Python 3.11+ و python-telegram-bot.

## محتوای بازی‌ها

- اطلاعات عمومی: ۲۵ سؤال چهارگزینه‌ای
- حدس کلمه: ۲۳ سؤال واژگان و املایی
- معما و چیستان: ۲۳ چیستان چهارگزینه‌ای
- چالش سرعت: ۲۳ سؤال محاسباتی و دانش سریع
- جرئت یا حقیقت: ۳۰ موضوع حقیقت و ۳۰ چالش جرئت
- حدس عدد: عدد تصادفی ۱ تا ۳۰ در هر دور

مجموع بانک سؤال‌های چهارگزینه‌ای: ۹۴ مورد. سؤال‌ها و موضوع‌های جرئت/حقیقت در شروع برنامه به دیتابیس افزوده می‌شوند. به‌روزرسانی بانک افزایشی و بدون حذف سؤال‌های موجود است؛ سؤال‌های پیش‌فرض تکراری نیز در اجرای مجدد دوباره درج نمی‌شوند.

## اجرای محلی

```bash
pip install -r requirements.txt
export BOT_TOKEN="توکن ربات"
export ADMIN_ID="شناسه عددی مدیر"
export DB_PATH="./bazichi.db"
python main.py
```

## استقرار Railway

1. فایل‌های `main.py`، `requirements.txt` و `Procfile` را در ریشه یک مخزن مستقل GitHub قرار دهید.
2. مخزن را به یک سرویس Railway متصل کنید.
3. در Variables مقادیر `BOT_TOKEN` و `ADMIN_ID` را ثبت کنید.
4. یک Volume با Mount Path برابر `/data` بسازید.
5. متغیر `DB_PATH` را برابر `/data/bazichi.db` قرار دهید.
6. سرویس را Deploy کنید. دستور اجرا در Procfile برابر `python main.py` است.

همه بازیکنان باید ابتدا در گفت‌وگوی خصوصی ربات `/start` را اجرا کنند. مسابقه دونفره و چندنفره از صف مشترک کاربران تشکیل می‌شود.
