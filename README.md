
# 🎮 BaziChiGameBot

ربات بازی گروهی فارسی تلگرام

## امکانات
- مسابقه اطلاعات عمومی
- حدس کلمه
- چیستان
- جرأت یا حقیقت
- حدس عدد
- سرعت عمل
- جدول امتیازات
- پروفایل بازیکنان
- پنل مدیریت
- پایگاه داده SQLite

## راه‌اندازی

ابتدا کتابخانه‌ها را نصب کنید:

pip install -r requirements.txt

سپس متغیرهای محیطی را تنظیم کنید:

BOT_TOKEN=توکن ربات
ADMIN_ID=شناسه عددی مدیر
DB_PATH=/data/bazichi.db

اجرای ربات:

python main.py

## تنظیمات تلگرام

در BotFather دستور زیر را اجرا کنید:

/setprivacy

ربات را انتخاب کنید و گزینه Disable را بزنید.

سپس ربات را به گروه اضافه کنید و دستور زیر را اجرا کنید:

/game

## استقرار Railway

1. یک پروژه جدید بسازید.
2. مخزن BaziChiGameBot را متصل کنید.
3. یک Volume بسازید.
4. مسیر Volume را روی /data قرار دهید.
5. متغیرهای محیطی را تنظیم کنید.
6. Deploy را اجرا کنید.

این پروژه مستقل است و به هیچ ربات دیگری وابستگی ندارد.
